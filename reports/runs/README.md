# Historical run-report limitations

The nine sibling files are immutable historical narrative records. Their run
identities and recorded metrics remain useful, but their prose is not
authoritative where it makes causal interpretations, calls the fixed
regression suite or the predefined publication query held-out, or states broad
upstream availability claims.

Use the canonical [technical retrospective](../EXPERIMENTS.md), its
claim-source ledger, and the manifest-bound evaluation JSON for corrected
interpretation and exact results. The historical report bodies remain frozen
so they continue to identify what was recorded at the time.
