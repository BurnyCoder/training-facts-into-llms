# Documentation publication receipts

The [audit-2026-10-29 receipt](audit-2026-10-29/receipt.json) records the completed
documentation publication from [merged source](https://github.com/BurnyCoder/training-facts-into-llms/commit/fe178e5fd045fef3534c8fc901f96776a20c7f4a).
Its [checksum](audit-2026-10-29/receipt.json.sha256) binds the receipt bytes.

Each repository entry records its original parent, resulting commit, source
document hashes, published document hashes, and the complete identities of
untouched Git/LFS objects. Completion required authenticated and anonymous
document reads, unchanged-object comparisons, and unchanged public visibility.
This is document/object verification, not a new model smoke test or acceptance
decision. Original publication receipts and evidence remain unchanged.

The [instruction audit](../INSTRUCTION_AUDIT.md) owns checklist findings and
historical gaps. The [security guide](../../docs/security-and-publication.md)
owns the publication procedure and retry boundaries.
