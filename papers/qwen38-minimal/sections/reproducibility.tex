\section{Reproducibility and evidence access}
\label{sec:reproducibility}
The exact base, public adapter, executed recipe, and raw evaluation have
immutable links in the bibliography and evidence appendix. Public evidence is
separate from ignored operational files. Some private-log observations remain
digest-bound transcriptions, and their content is not derivable from hashes.
\citep{qwen38,qwen38adapter,qwen38source}\claimsource{audit}

From the repository root, document regeneration is offline:
\begin{verbatim}
uv run --frozen training-facts-into-llms results build
uv run --frozen training-facts-into-llms results check
make -C papers/qwen38-minimal
\end{verbatim}
These commands do not allocate models, read publication credentials, train, or
upload. The named PDF has its own source and build directory. The original
Qwen3.5 paper and PDF remain unchanged.

Future model-level verification requires compatible hardware. A training
reproduction must start from the untouched base, satisfy the reviewed gates,
and receive a new evidence identity. Expanded BF16 and QLoRA rungs were not
run; they remain deferred and are not negative results. The exploratory chat
check does not revise acceptance.\claimsource{manifest}\claimsource{audit}
